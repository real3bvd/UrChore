# UrChore

UrChore is a Flutter household chore management app. Adults can create or join
a household, manage their profile, assign chores to members, use recurring
schedules, and follow weekly progress from the Home screen.

## Features

- Sign in and registration with persistent local accounts
- Create or join a household with an invite code
- Profile colors, hedgehog avatars, camera photos, and gallery photos
- Chore templates and custom chores
- Member assignment, priorities, due dates, and recurrence
- Weekly calendar indicators and household progress
- Persistent warm light and dark themes
- Local SQLite storage on supported native platforms

## Run The Project

1. Install Flutter and an Android emulator or another supported target.
2. From the project directory, run:

```bash
flutter pub get
flutter run
```

## Tests

```bash
flutter analyze
flutter test
```
